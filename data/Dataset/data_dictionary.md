# Data Dictionary

| Field                | Description                                      | Example Values                        |
|----------------------|--------------------------------------------------|---------------------------------------|
| LearnerID            | Unique learner identifier                        | L001, L002, L003                      |
| AgeBand              | Age group of learner                             | 18-24, 25-29, 30-35                   |
| Province             | Province or area                                 | Western Cape, Gauteng, KZN            |
| DeviceAccess         | Device used for learning                         | Laptop, shared laptop, phone only     |
| InternetAccess       | Quality of internet access                       | Reliable, unstable, limited           |
| DigitalConfidence    | Self-rated digital confidence (1=low, 5=high)    | 1, 2, 3, 4, 5                         |
| ProgrammingConfidence| Self-rated programming confidence (1=low, 5=high)| 1, 2, 3, 4, 5                         |
| AIFamiliarity        | Familiarity with AI (1=low, 5=high)              | 1, 2, 3, 4, 5                         |
| EmploymentStatus     | Current employment status                        | Unemployed, under-employed, employed part-time |
| SupportNeed          | Main support need                                | Transport, data, academic support, mentoring |
| AttendanceRisk       | Risk of poor attendance                          | Low, medium, high                     |
| Notes                | Free-text notes                                  | Short comments                        |
