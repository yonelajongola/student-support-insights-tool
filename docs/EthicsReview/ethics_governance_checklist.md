# Ethics Governance Checklist

This checklist supports the AI/Data Ethics evidence requirement for the Student Support Insights Tool.

| Governance Area | Checklist Question | Prototype Status |
|---|---|---|
| Purpose limitation | Is the data used only for learner support planning? | Yes |
| Data minimisation | Are direct identifiers avoided? | Yes |
| Consent | Would learners be told what data is collected and why? | Included in privacy notice |
| Human review | Are risk scores treated as support signals only? | Yes |
| Bias review | Are access barriers interpreted as resource needs instead of learner weakness? | Yes |
| Explainability | Can staff see why a learner was flagged? | Yes, reason codes are shown |
| Harm prevention | Are exclusion/disciplinary decisions excluded from automation? | Yes |
| Security | Is stronger security recommended for live deployment? | Yes |
| Retention | Is unnecessary long-term storage discouraged? | Yes |
| Accountability | Should staff record interventions and follow-up? | Yes |

## Ethics Improvement Added
The ethics evidence was strengthened by adding a clear human-review workflow, risk register style fairness risks, stronger privacy notice text, retention guidance, and implementation controls for future live deployment.
